## 2026-09-29 验收结果

手机尺寸（Pixel 7）和桌面 Chromium 两套端到端测试全部通过，总耗时约 1 分钟：

1. 管理员登录并创建活动；刻意延迟照片列表响应，确认加载期间导航禁用，完成后正常进入管理页。
2. 填写姓名、学号、账号、密码，上传公开测试标准照；实际检测、对齐、编码成功，数据库保存 128 维特征。
3. 退出登录后拍照/选图上传，服务器检索到已录入用户并签到成功，公开结果仅显示掩码姓名。
4. 重复上传仍只保存一条签到记录；另一位未录入人物被拒识；无脸图片收到重新拍摄提示。
5. 登录查询本人记录；管理员查询活动名单；普通用户访问管理接口返回 403。
6. 1/5/10 并发请求全部受理并完成，每个活动仍只有一条签到记录。

另在 ECS 验证了 Worker 停止/启动：心跳失效后公网 readiness 返回 503，上传返回“人脸识别服务正在准备”；启动后无需重新下载模型即恢复就绪。Docker、Nginx、证书续期定时器均已启用开机自启。此次未重启整台 ECS，不把容器重启测试写作整机重启验收。

原人员库为空。验收后已删除两套测试账号、活动和 40 张匿名测试照片，保留课程管理员；没有保留测试签到作为正式记录。另创建“云计算课程验收签到”活动，开放至北京时间 **2026-10-06 21:14**，可由管理员取消并按实际验收时间新建活动。

## ECS 实测

客户端通过公网 HTTPS 发起请求；并发批次直接上传同一张约 773 KiB 的公开 PNG，页面普通上传会另外压缩。每档只执行一个批次，样本量小，以下数据用于验证突发请求处理，不能外推持续容量或识别准确率。

| 并发数 | 手机尺寸流程完整耗时 p95 | 桌面流程完整耗时 p95 |
| --- | --- | --- |
| 1 | 1.304 秒 | 4.117 秒 |
| 5 | 2.046 秒 | 3.974 秒 |
| 10 | 5.282 秒 | 5.769 秒 |

10 并发受理耗时分别为 432–4,615 毫秒、987–4,620 毫秒。完整耗时包含公网传输、数据库处理、dispatcher 投递、排队、模型推理和轮询；两次单请求耗时不同体现网络和投递周期的影响。

数据库快照中的 40 次成功编码（包括注册、签到与未录入人员的编码）耗时为 **29.18–70.66 毫秒，中位数 30.71 毫秒**，与完整反馈耗时分开统计。无人脸任务未生成编码，不计入此统计。

在北京时间 21:11–21:14 的容器采样中：

| 指标 | 观测到的最大值 |
| --- | --- |
| Worker 内存 | 347.2 MiB |
| API 内存 | 143.4 MiB |
| 7 个应用容器同时占用内存 | 1,023.41 MiB |
| Worker CPU | 139.41% |
| API CPU | 139.56% |

Docker CPU 的 100% 表示一个 vCPU，4 vCPU 上总量可到 400%；这些是采样观测值，不保证捕获瞬时峰值。内存统计不含宿主机和既有 Hadoop 等其他服务。

## 提交材料与使用

本机材料目录：`artifacts/iteration-three-ecs/`。打包文件：`artifacts/iteration-three-ecs-submission.zip`，不进入 Git。

- `test-results/*/01` 至 `07`：注册、录入、签到成功、未录入拒识、无脸提示、本人记录和服务器数据库截图。
- `database.html`：不含密码、会话令牌和特征向量的数据库快照。
- `concurrency.json`、`container-stats.jsonl`、`resource-summary.json`、`inference-summary.json`：原始数据与统计。
- `deployment.json`、`worker-recovery.json`、`test-cleanup.json`：部署、Worker 恢复和测试清理证据。

管理员登录信息只保存在本机 `artifacts/production-admin.json`，权限 600，**不包含在提交压缩包中**。管理员可以创建活动、查看名单、管理用户和照片；也可以上传自己的标准照。管理员账号计入当前 10 个账号上限。

普通用户先注册并等待“人脸录入成功”，再退出登录或回到签到首页，选择活动并拍照签到。活动过期后，由管理员创建新活动即可。演示前开启 ECS，确认识别服务就绪；不使用时可以关机。长期关机超过证书有效期时，需等待开机续期完成。

## 验证边界

材料中的手机页面为浏览器设备模拟，使用 NASA / 美国海军公开测试照片，来源见 `backend/tests/fixtures/README.md`。实际手机相机、本人不同光照/角度的照片、真实未录入人员及阈值校准仍需现场验收；没有活体检测，不能宣称防照片代签。没有新增收费云服务或调用 FRS，现有 ECS、云盘与公网费用仍以华为云账单为准。
